```
  【3つの役割の言い方】
  一般的には プレゼンテーション層＝表示 / アプリケーション層＝処理 /
  データ層＝保存 と説明される。漢語のままだと初日には入らないので
  動詞に開いている。
    画面 → 見せる
    処理 → 動かす
    保存 → 覚える

  処理の言い方は何度も往復した。落とした案と理由：
    「考える」          → サーバーが考えるわけではない
    「決める」「さばく」  → 判断だけを指し、受け取って返す仕事が消える
    「受け取って、返す」  → 主語も目的語もなく、中身のない中継役に読める
    「たのまれてやる」    → 「やる」が雑で書き言葉として落ち着かない
    「はたらく」        → 意味が広すぎて、何をしているのか残らない
  「動かす」を選んだのは、3つを同じ形にそろえて音で覚えられるようにするため。
  意味は広いので、中身は 21枚目「おすすめを選ぶ」で埋める。

  3つ目は「データ」から「保存」に変えた。データは物の名前なので
  「見せる／動かす」と品詞がそろわず、3つ並べたときに1つだけ浮いていた。
  「動作」も候補に挙がったが採らなかった。31枚目で JavaScript を
  「押したら動く」と説明するので、動くのが画面なのかサーバー側なのか
  区別できなくなる。

  ただし世の中の解説と講義名では「データ」が使われる。
    3層アーキテクチャ → データ層（26枚目の図はこの正式名称のまま）
    Deno KV の講義   → データベース
  役割の3語として並べるときだけ「保存」を使う。
```

## 8. ちがい① どうやって手元に届くか

```
【4分】理由その1。ネイティブアプリとの対比。
  問い → 既知の例 → 未知の例 の順で運ぶ。これが元資料でいちばん
  分かりやすかった流れなので踏襲する。

＜台本＞
「アプリ」と言われると、スマホに入っているアプリを想像する人が多いと思います。
あれは「ネイティブアプリケーション」といって、Webアプリケーションとは別物です。

まず考えてほしいんですが、**アプリって、どうやってみなさんの手元に届いていますか？**

スマホアプリの場合は、アプリストアですよね。
作った人がストアに置いて、みんながそこからダウンロードして、
自分の端末の中にアプリ本体が入る。

では、Webアプリケーションはどうでしょう。ストアには売っていません。
かわりに **Webサーバー** というところに置いてあって、
みなさんがURLを開くたびに、そこから届きます。

**アプリストアの代わりが、Webサーバーです。** だからサーバーが必要なんです。

・「どうやって届くのか」という問いを先に立てるのが肝。
  いきなり「サーバーがあります」と言うより、
  「ストアの代わりが要る」→「それがサーバー」の順のほうが腑に落ちる。
・ストアは全員が知っている。既知から未知へ運ぶ。

・そのうえで結果のちがいを言う。
  スマホアプリは本体が端末の中にあるので、飛行機の中でも起動する。
  Webアプリケーションは本体がサーバーにあるので、**ネットがないと使えない**。
  「インターネットを介して使うソフトなんだな」と思ってもらえればOK。
・逆に、開くたびに届くのでつねに最新版になる。更新ボタンを押さなくていい。
  これは利点として言い添えると納得が早い。

・「実体」「向こう側」のような言い方は避ける。何を指すのか伝わらない。
  アプリ本体、サーバー、と具体的な名前で言い切る。
・サーバーはここが初出。「頼まれたものを渡してくれるコンピュータ」と
  一度だけ言う。深入りはしない。第2章で場所の話として扱う。
```

## 10. ちがい② 読むだけか、操作できるか

```
【3分】理由その2。よく混同されるほうを潰しておく。

＜台本＞
もうひとつ、よく混同されるものとして「Webサイト」があります。

Webサイトは「情報を読むもの」で、誰が見ても同じページが見られます。
Webアプリケーションは「操作して使うもの」なので、人によって見える内容が違います。

・会社の紹介ページは誰が見ても同じ。YouTube のおすすめは人によって違う。
  imgs/jigjp.site.png を Webサイト側の例として見せると効く。
```

```
授業が終わったあとに思い出したことでも投げてください。

・「質問はありますか？」と全体に聞かない。沈黙すると場が重くなる。
  スレを読むと宣言すれば沈黙が発生しない。
・名前は読み上げない。「これ書いた人〜」のような呼びかけもしない。
・件数が少なくても、冒頭でシードした3件に答えれば時間は埋まる。

・「授業後でも大丈夫」を明示するのが効く。その場で質問を思いつく人は少ない。
  ここで締め切らないと言っておくと、あとから来る。
  メンターが返すと言っているので、自分ひとりで抱えないこと。
・スレは2週間開けたままにすると宣言して終わる。
・巻いた場合は無理に埋めず、早めに終わる。
  初日は「予定どおり終わった」こと自体が信頼になる。
```
