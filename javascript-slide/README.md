# JavaScript を始めよう — 基本文法をコンソールで

> この資料は jig.jp のインターン／勉強会向けに作成されたものです。

## 目的

JavaScript の基本文法を、**スライド内のコンソールで動かしながら**学びます。
変数・条件・繰り返し・関数・オブジェクト・クラス、そして非同期処理（Promise / async・await）やブラウザ API まで、手を動かして体験します。

元になった自習用ドキュメント（[jigintern/intern-dev-tutorial の javascript](https://github.com/jigintern/intern-dev-tutorial/blob/main/javascript/DOCS.md)）を、勉強会向けに再構成したものです。

## 対象

- プログラミング／Web 開発の初学者
- 「HTML/CSS を始めよう」を終えていると、よりスムーズです

## 準備

- **ブラウザだけで OK**。スライド内の「▶ 実行」できるコード欄で、その場で試せます
- 手元で試したい人は、開発者ツールの **Console**（`Ctrl`/`Cmd`+`Shift`+`I` →「Console」）に打っても同じように動きます
- インストールは不要
